# 模拟外交部发言现场 HTML 小游戏

## 互动制作前置清单

- 课堂目标：学生以外交部发言人视角，围绕黄岩岛议题训练“地理事实 + 历史材料 + 稳健表达”的现场回应能力。
- 学生角色：两名学生代表上台，每人回应一名记者；另一名学生可从旁辅助判断证据。
- 游戏场景：正式新闻发布厅第一视角。学生不能移动人物，但可用鼠标左右环顾会场，点击举手记者触发提问。
- 地图与材料：学生界面使用简短提示卡，不展示未经审图的完整边界地图；教师资料区保留原始材料说明。
- 视觉资产：AI 生成无标识宽画幅发布厅背景；AI 生成第一视角讲台和手部透明前景；记者席使用背景图中的真实坐席氛围，页面只保留可点击热区。
- 页面绘制内容：微信通话式拨打外交部现场电话开场、举手热区、点击高亮、题目大框、提示卡、居中标准答案框、最终总结、教师控制面板。
- 1小时内目标质量：完成可投屏、可本地打开、可完整走完两题的课堂版本；保留开场动画开关和音效开关。
- 超时降级方案：关闭开场动画和音效，只保留第一视角背景、记者点击、提示卡和居中标准回应。

## 已定设计

- 风格：严肃仿真为主，轻量闯关反馈为辅。
- 记者数量：画面中呈现多名记者，只有 2 名举手记者可点击。
- 开场流程：点击“拨打外交部现场电话” -> 播放国内音效素材铃声 -> 约 4 秒后自动进入发布会现场。
- 答题流程：点击记者 -> 中间显示题目和提示卡 -> 学生讨论并现场回答 -> 点击“结束本题” -> 居中展示教师标准答案。
- 纠错逻辑：不再设置材料选择玩法，教师根据学生口头回答现场点拨。
- 最终总结：始终呈现完美发布会成果，不记录过程错误。
- 隐藏教师资料：右上角小图标长按 2 秒打开，提供演示控制、材料口径和现场降级方案。
- 铃声素材：`assets/call-ringtone.mp3` 由教师提供的本地文件 `纯音乐-电话铃声.ogg` 截取转码生成，用于拨打现场电话环节。
