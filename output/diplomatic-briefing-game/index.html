外交部例行记者会模拟现场

移动鼠标环顾会场，点击进入视野的举手记者。

教师材料

本区供教师备课和现场点拨使用，不参与学生证据选择。

课堂主线

真实情境 -> 记者提问 -> 学生筛选证据 -> 发言人回应 -> 教师用证据链收束。

材料口径

  • 历史先占与持续管辖：早期认知、长期开发利用、官方测量、命名确认与持续管理共同构成证据链。
  • 条约界限：相关国际条约界定菲律宾领土范围，未将黄岩岛纳入其中。
  • 自然地理线索：大陆架自然延伸与马尼拉海沟等可作为空间解释材料。

点拨提醒

不要让学生把“距离近”“渔民去过”“态度强硬”当成单独充分依据，要引导他们组合材料、克制表达。
